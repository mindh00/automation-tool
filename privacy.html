Privacy policy

Last updated: November 24, 2026

Automation tool ("the tool") is a self-hosted application that runs on its owner's own computer. This policy explains what the tool does with data it receives through Google sign-in.

What data the tool accesses

When a channel owner signs in with Google, the tool requests read-only access to:

  • YouTube Data API (youtube.readonly): the channel's name, statistics, video list and public video data, and comments on the channel's own videos.
  • YouTube Analytics API (yt-analytics.readonly): the channel's own analytics reports (views, watch time, traffic sources, audience countries and age groups, retention).
  • YouTube Analytics monetary reports (yt-analytics-monetary.readonly): the channel's own estimated revenue and CPM, when the channel is monetized.

How the data is used

The data is used only to show the channel owner their own performance, research their niche and plan their next videos inside the tool. It is not used for advertising, not sold, and not shared with any third party.

Where the data is stored

All data, including the sign-in token, is stored only on the owner's own computer (a local database and a local token file). The tool has no central server and no copy of the data leaves that computer.

Retention and deletion

The channel owner can disconnect at any time by removing the channel from the tool, which deletes its local token and data, and by revoking access at myaccount.google.com/permissions.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact
